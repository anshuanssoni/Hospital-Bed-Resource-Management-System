# Hospital Bed & Resource Management System
---------------------------------------------
An advanced Excel-based Hospital Management & Analytics System built using VBA, Pivot Tables, Dynamic Formulas, Interactive Dashboards, and Automation Logic. The system automates patient admission, bed allocation, doctor assignment, billing operations, insurance calculations, and executive-level hospital analytics.

## Features

- Dynamic Patient Admission Form
- Smart Bed Allocation Engine
- Doctor Assignment Automation
- Billing & Insurance Logic
- Interactive Executive Dashboard
- KPI Monitoring System
- Real-Time Alerts & Insights
- Slicers & Timeline Filters
- VBA Automation
- Pivot Analytics

## Tools & Technologies

- Microsoft Excel
- VBA Macros
- Pivot Tables & Charts
- XLOOKUP
- Conditional Formatting
- Slicers & Timeline
- Data Validation
- Dynamic Dashboards

## Business Problem Solved
--------------------------
Traditional hospital operations often rely on manual processes for patient admission, bed allocation, doctor assignment, and billing management. This project centralizes and automates hospital workflows while providing real-time analytics and operational visibility.

- Resource Allocation Insights
